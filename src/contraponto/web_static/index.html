 A PERGUNTA É O COMEÇO

Mais contexto.
Outras perspectivas.

Esta é uma demonstração independente de chat, inspirada no WhatsApp Web. Não se conecta ao WhatsApp.

  1. Análise por solicitação no grupo. Nenhuma mensagem é analisada automaticamente. Use “Analisar mensagem” para pedir análise linguística e verificação de evidências. O resultado fica visível aos quatro perfis; o score linguístico não comprova falsidade.
  2. Conversas entre pessoas. Apenas os dois perfis participantes acessam a conversa. Não há análise automática. “Encaminhar ao Contra” envia somente a mensagem escolhida ao chat do bot de quem clicou; o relatório fica nesse chat.
  3. Um diálogo com as evidências. No chat com o Contra, envie ou encaminhe uma notícia para receber conclusões e fontes por alegação, independentemente do score linguístico.

Cada conversa guarda até 80 mensagens em memória e é apagada ao reiniciar. São perfis de teste: quem retomar um perfil disponível verá o histórico dele. Não há autenticação pessoal nem criptografia de ponta a ponta.
